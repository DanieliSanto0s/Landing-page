# Landing Page

Este projeto foi desenvolvido como parte do curso The Odin Project, com o objetivo de praticar e aplicar conceitos fundamentais de HTML e CSS, especialmente o uso de Flexbox para estruturação de layout. A landing page tem caráter exclusivamente ilustrativo, sem conteúdo funcional, servindo como exercício prático para o aprimoramento de habilidades em desenvolvimento web.

## Objetivo

- Praticar a aplicação de Flexbox para organização de elementos;
- Consolidar conhecimentos fundamentais de HTML e CSS;
- Servir como base para estudos futuros de design responsivo e interatividade com JavaScript.

## Estrutura

O projeto é composto por:

- `index.html`: estrutura principal da página;
- `style.css`: arquivo de estilos.
